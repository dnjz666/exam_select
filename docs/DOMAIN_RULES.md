## §2 数据口径（DATA_DICTIONARY 种子）

### 2.1 `min_rank` 的口径（**最容易被搞错，必须统一**）

- `min_rank` = 该投档单位**当年投档最低分所对应的位次**（即"最低位次"）
- 若官方只公布最低分、未公布最低位次：**必须**用当年一分一段表反查得到，并在 `data_quality` 标注 `DERIVED`
- **位次数值越小 = 越靠前 = 越难考**。全系统统一此约定，注释里写清楚，防止方向写反。

### 2.2 `data_quality` 取值

| 值 | 含义 | 是否参与概率计算 |
|---|---|---|
| `OK` | 官方直接公布，字段完整 | ✅ |
| `DERIVED` | 由最低分 + 一分一段表反查得到 | ✅（权重 ×0.9） |
| `MISSING_RANK` | 有分数无位次且无法反查 | ❌ |
| `COLLECTED` | 数据来自征集志愿 | ⚠️ 单独标记，参与但打 `COLLECTED_ONLY` 风险 |
| `SUSPECT` | 校验不通过（如位次与分数明显矛盾） | ❌ 且触发 `SUSPECT_DATA` 高风险 |

### 2.3 `total_candidates` 口径

= 该省该年该科类的**实际参加高考人数**（非报名人数，非计划数）。
位次归一化的分母，错了会让所有概率系统性偏移。**必须记录来源。**

### 2.4 选考科目要求编码

```json
{"mode": "all_of", "subjects": ["物理", "化学"]}   // 必须同时选考物理和化学
{"mode": "any_of", "subjects": ["物理", "历史"]}   // 二者选一即可
{"mode": "none",   "subjects": []}                // 不限
```

3+3 模式下考生恰好有 3 门选考科目，判定为集合关系：
- `none` → 恒通过
- `all_of` → `set(要求) ⊆ set(考生选考)`
- `any_of` → `set(要求) ∩ set(考生选考) ≠ ∅`

⚠️ **陷阱**：部分省份要求写作"物理和化学"但实际是"物理或化学"。**必须逐条核对原始招生计划文本**，
不得靠字符串直觉解析。ETL 必须对无法解析的要求标记 `SUBJECT_REQ_PARSE_FAILED` 并**拒绝入库**。

### 3.1 参数标定纪律

1. **任何参数改动必须重跑回测**（§6.9），并在 `docs/DECISIONS.md` 附**改动前后**指标对比表。
2. 参数默认值来自经验先验，**不是真理**。M2 结束后应做**敏感度分析**：
   对 `year_weights` / `plan_beta` / `min_sigma_rel` 做网格扫描，输出热力图，
   选出在回测上最优且**不过拟合**（跨省份、跨年份稳定）的取值。
3. 若某参数在某省表现差异大 → 做成**省份覆盖**，不要全局改动。

## §4 名师经验规则库

> 编码规则：`R-xxx`。每条必须能映射到代码中的具体位置。凭空的经验不进这个库。

### 4.1 定位与梯度

| ID | 规则 | 落地位置 |
|---|---|---|
| R-001 | 跨年比较一律用位次，分数只用于展示。 | `rank.py` / UI |
| R-002 | 考生人数变化必须归一化：`R_adj = R × (N_今年 / N_当年)`。 | `rank.py::normalize_rank` |
| R-003 | 至少 3 年数据才谈得上"趋势"；只有 1 年数据必须降置信度并提示。 | `probability.py` Step 8 |
| R-004 | 位次逐年下降（数值变小）说明该校越来越热，要做趋势修正。 | Step 3 |
| R-005 | 计划数变化是强信号，必须修正；计划大幅缩减的学校要警惕分数线上涨。 | Step 4 |
| R-006 | 招生计划 < 5 人的单位，历史位次无预测价值，必须降置信度 + 打风险。 | Step 8 / `risk.py` |
| R-007 | 保底/垫底志愿：**考生位次必须比该单位近三年最难年份的最低位次还靠前 ≥ safety_margin（默认 60%）**，即 `min(近三年归一化最低位次) ≥ 考生位次 × 1.60`。（⚠️ 原表述"单位位次优于考生位次"方向写反——那等于单位更难=不安全，见 DECISIONS ADR-009 勘误 2；阈值本身在 M5 因修正 M1 数据缺陷而由 30% 重标定为 60%，见 ADR-014） | `risk.py::SAFETY_NOT_SAFE` / `probability.py::_safety_gated_tier` |
| R-008 | 垫底志愿数量：≥3 个，且 ≥5% 总志愿数。 | `planner.py` 结构校验 |
| R-009 | 冲稳保配额 25/40/25/10；某层不足时向**更保守**方向借位，绝不向更激进方向借。 | `planner.py` |
| R-010 | 平行志愿检索严格按填报顺序，**最想去的必须放最前**，不能按概率排序。 | `planner.py` Step 3 |
| R-011 | 兜底志愿考虑"双保险"：选 2 个层次差异较大的保底校，避免同层次集体波动。 | `planner.py` |

### 4.2 风险与陷阱

| ID | 规则 | 落地位置 |
|---|---|---|
| R-020 | 院校专业组模式下不服从调剂 = 主动接受退档风险，必须 HIGH 级提示。 | `risk.py::NO_OBEDIENCE` |
| R-021 | 冲进专业组却排斥组内专业 = 真实事故。组内必须有**可接受**专业兜底。 | `risk.py::GROUP_UNACCEPTABLE` |
| R-022 | 专业+院校模式（浙江/山东）无调剂问题，`NO_OBEDIENCE` 规则**不适用**。 | `rules/*.py` |
| R-023 | 征集志愿线通常低于正常投档线，若历史数据仅来自征集，会**高估**概率。 | `risk.py::COLLECTED_ONLY` |
| R-024 | 体检受限是硬伤，必须在过滤阶段就剔除，不能只在风险里提示。 | `filters.py` |
| R-025 | 中外合作办学 / 民办 / 独立学院学费可达数万，必须在卡片上明示金额。 | UI + `scoring.py` |
| R-026 | 大类招生有分流风险，进校后可能分不到意向专业，需提示。 | UI `remarks` |
| R-027 | 新增专业/新增院校无历史数据，用**同层次、同地区、同专业类**的单位做类比，并标注不确定性。 | Step 1 回退分支 |
| R-028 | 数据自相矛盾（位次与分数不匹配）时宁可不推，也不推可疑数据。 | `etl/validate.py` |

### 4.3 沟通与呈现

| ID | 规则 | 落地位置 |
|---|---|---|
| R-030 | 概率必须以**区间**呈现，禁止单一精确数字。 | UI / API |
| R-031 | 禁止"保证录取""一定能上""百分百""稳上"等绝对化表述。 | `guard.py` 词表 |
| R-032 | 每条推荐必须可展开查看历史证据（年份/最低分/最低位次/计划数/来源链接）。 | UI |

| R-035 | 报告与首次对话必须含免责声明：仅供参考，以考试院官方文件与招生章程为准。 | UI / `prompts.py` |

## §5 偏好打分细则（`core/scoring.py`）

所有分项归一到 `[0, 1]`，`utility = Σ w_k · score_k`，权重由考生设定并归一化。

### 5.1 `level_score`（院校层次）

| 特征 | 分数 |
|---|---|
| 985 且双一流 | 1.00 |
| 211 且双一流 | 0.85 |
| 双一流（非 985/211） | 0.75 |
| 省重点 / 部属 | 0.60 |
| 普通公办本科 | 0.45 |
| 民办 / 独立学院 | 0.20 |

> 若考生在"专业优先"模式下，院校层次权重应下调；在"院校优先"模式下上调。UI 提供模式选择。

### 5.2 `major_match_score`

| 匹配关系 | 分数 |
|---|---|
| 与意向专业**完全一致** | 1.00 |
| 同一专业类（如"计算机类"内） | 0.80 |
| 同一学科门类（如"工学"内） | 0.55 |
| 相关门类（预定义映射） | 0.30 |
| 不在意向范围 | 0.00 |

### 5.3 `region_score` / `city_score`

- `region_score`：考生勾选的意向省份 = 1.0；未勾选 = 0.0；"可接受" = 0.5
- `city_score`：一线 1.0 / 新一线 0.85 / 二线 0.7 / 三线 0.5 / 其他 0.35
  （城市分级表单独维护，带来源）

### 5.4 `tuition_score`

```
tuition <= budget_comfortable          → 1.00
budget_comfortable < tuition <= budget_max → 线性降到 0.3
tuition > budget_max                   → 硬约束剔除（见 filters.py）
```

### 5.5 `misc_score`

保研率、硕士点/博士点、宿舍条件、转专业政策等，各自归一后加权。
**每项必须返回 `score_breakdown`，让考生看见"为什么这个分"。**

## §6 数据合规

1. **模拟数据**：院校名、专业名为公开信息；分数线与位次为**模拟值**，
   必须落库为 `is_synthetic=1`，UI 顶部常驻提示"当前为模拟数据，不可用于真实填报"。
2. **真实数据**：接入前确认
   - 数据来源的授权与使用条款
   - 是否允许缓存与二次展示
   - 是否需署名来源
3. **个人信息**：考生档案（分数、位次、体检结论）属敏感个人信息
   - 本地优先存储，默认不上传
   - 若调用第三方 LLM，**不得**将考生真实身份信息（姓名/身份证/准考证号）放入 prompt
   - 提供"清除我的数据"功能
4. **责任边界**：系统只提供决策辅助。最终以各省考试院官方文件、招生计划与高校招生章程为准。

## §7 黄金用例规范（`backend/tests/golden/`）

每条用例为 JSON，人工构造，**答案已知**。M2 必须交付 ≥20 条。

```json
{
  "case_id": "G-001",
  "description": "考生位次稳定优于目标位次，计划不变，应为稳档",
  "student": { "province": "zhejiang", "rank": 9000, "subjects": ["物理","化学","生物"] },
  "history": [
    {"year": 2024, "min_rank": 9000,  "plan_count": 20, "data_quality": "OK"},
    {"year": 2023, "min_rank": 9500,  "plan_count": 20, "data_quality": "OK"},
    {"year": 2022, "min_rank": 9200,  "plan_count": 20, "data_quality": "OK"}
  ],
  "plan_count_current": 20,
  "expected": { "tier": "WEN", "prob_min": 0.55, "prob_max": 0.72, "confidence": "HIGH" }
}
```

### 7.1 必须覆盖的场景（每一类至少 2 条）

| 类别 | 场景 |
|---|---|
| 基础 | 稳档 / 冲档 / 保档 / 垫档 各一 |
| 边界 | 概率正好落在分层边界（0.10 / 0.40 / 0.75 / 0.93） |
| 趋势 | 位次逐年变热 / 逐年变冷 |
| 计划 | 计划突增 50% / 突减 50% |
| 大小年 | cv > 0.15 的剧烈波动单位 |
| 数据缺失 | 仅 1 年数据 / 0 年数据（必须返回 NO_DATA） |
| 质量 | `data_quality=MISSING_RANK` / `SUSPECT` |
| 选科 | `all_of` / `any_of` / `none` 三种匹配与不匹配 |
| 硬约束 | 色盲受限 / 单科不达标 / 学费超限 |
| 调剂 | 院校专业组未勾选服从调剂 |

### 7.2 方向性断言（最容易写反，必须有测试）

```
✅ 考生位次变小（更强）→ 概率不下降
✅ 计划数增加         → 概率不下降
✅ 历史位次整体变小（单位更难）→ 概率**不上升**（⚠️ 原文写"不下降"，方向与 §2.1 位次口径及 §6.2 公式矛盾；详见 DECISIONS ADR-009 勘误附注）
✅ σ 变大             → 概率向 0.5 收缩
```

> ⚠️ **勘误（2026-02，ADR-009）**：本节原 G-001 示例把"考生 10000 vs 单位 9000/9500/9200"标为
> "考生位次稳定优于目标位次、应为稳档"。按 §2.1「位次数值越小越靠前」与 §6.2 公式，
> 该组合实为 `TOO_RISKY`（要得 0.55~0.72 应把考生位次改到 ~9000，示例已据此更正）。
> `backend/tests/golden/golden_probability.json` 的 **G-018** 专门锁定这一方向，防止被"改回错误示例"。

用 `hypothesis` 写成性质测试，比单点断言更能抓到方向写反的 bug。

## §8 术语表

| 术语 | 含义 |
|---|---|
| 位次 | 考生成绩在全省该科类中的排名，数值越小越靠前 |
| 一分一段表 | 每个分数的人数与累计人数，位次换算的地基 |
| 等效分 | 把今年位次按往年一分一段表换算出的往年分数，便于人理解 |
| 投档单位 | 平行志愿的检索与投档对象，为"专业(类)+院校"或"院校专业组" |
| 院校专业组 | 高校将选考科目要求相同的专业打包成组，组内可调剂 |
| 服从调剂 | 所填专业未录时是否接受调剂到组内其他专业 |
| 大小年 | 某单位录取位次一年高一年低剧烈波动 |
| 征集志愿 | 首轮未录满后的补录，分数线通常低于正常投档线 |
| 冲稳保垫 | 按录取概率划分的志愿梯度分层 |
| 滑档 | 所有志愿都未投出 |
| 退档 | 投档后因不服从调剂/体检/单科等原因被退回 |
